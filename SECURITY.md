# Security Policy

Please report security issues privately.

Do **not** open a public GitHub issue for a vulnerability.

## Reporting

Use GitHub's private vulnerability reporting:

https://github.com/alpdogan/gittygotchi/security/advisories/new

If that form is unavailable, contact the maintainer privately through GitHub (@alpdogan) without attaching secrets, tokens, or exploit payloads.

## Please include

- A description of the issue
- The affected URL or component
- Steps to reproduce
- The impact
- Whether you have a patch

Do not include production secrets, Cloudflare credentials, or personal data belonging to other people.

## Scope

GittyGotchi consumes public GitHub data only. Reports around SVG injection, SSRF, cache poisoning, D1 races, and request amplification are in scope.

## Response

The maintainer will acknowledge valid reports and work on a fix before any public disclosure.
